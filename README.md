# 📦 MAGACIN ERP SISTEM

Kompletan sistem za upravljanje magacinom po ERP standardima.

## Tehnologije
- **Frontend**: Visual Studio WinForms (.NET)
- **Backend**: C#
- **Baza podataka**: SQL Server 2022
- **ORM**: Entity Framework / ADO.NET

## Moduli
- Master podaci (Artikli, Lokacije, Dobavljači)
- Prijema materijala
- Izdavanja materijala
- Transferi i prebrojavanje
- Izveštaji i analitika
- Administracija
